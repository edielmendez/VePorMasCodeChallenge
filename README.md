# VePorMasCodeChallenge!

Android Code Challenge que implementa la API  [https://jsonplaceholder.typicode.com](https://jsonplaceholder.typicode.com) , utilizando la arquitectura MVI.

# Stack
- Kotlin
- Androidx Lifecycle
- kotlinx Flows
- Retrofit2
- Compose
- Glide
- Dagger Hilt

# Notas

- La implementación exacta esta en la rama development
- El code challenge indicado en el documento esta implementado en su totalidad, solo no tiene el renderizado de la imagen que trae el json de respuesta, esto debido a que la API, ya no lo permite.
